# QUALITAT S.A.C - OpsControl

## 📱 Centro de Control & Sustentos

Aplicación Progressive Web App (PWA) para gestión de incidencias en call center.

### ✨ Características

✅ **Instalable en móvil** - Se instala como app nativa  
✅ **Funciona offline** - Service Worker para acceso sin internet  
✅ **Responsive** - Optimizado para todos los dispositivos  
✅ **Dos roles**: Operador y Supervisor  
✅ **Reportes de incidencias** con fotos y descripción  
✅ **Chat en tiempo real** con supervisores  
✅ **Panel gerencial** con métricas en vivo  

### 🚀 Cómo instalar en tu móvil

#### **Android (Chrome, Edge, Brave):**
1. Abre: https://chero272016-cmyk.github.io/qualitat-sac-reportes/
2. Toca el menú (⋮) → "Instalar app"
3. ¡Listo! Aparecerá en tu pantalla de inicio

#### **iPhone (Safari):**
1. Abre: https://chero272016-cmyk.github.io/qualitat-sac-reportes/
2. Toca Compartir → "Agregar a pantalla de inicio"
3. ¡Listo! Aparecerá como app en tu pantalla de inicio

### 👥 Roles

**Operador:**
- Reportar incidencias con fotos
- Detallar el problema
- Chat con supervisores
- Registro de sustentos

**Supervisor:**
- Panel de control en vivo
- Métricas de incidencias
- Revisar sustentos recibidos
- Exportar reportes Excel
